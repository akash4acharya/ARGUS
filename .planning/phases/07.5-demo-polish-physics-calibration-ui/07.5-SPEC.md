# Phase 7.5: Speed Physics Calibration, Manual Zone UX & Clear Logs — Specification

**Created:** 2026-11-26  
**Ambiguity Score:** 0.00 (All 4 design branches locked via `/grill-me`)

---

## Goal
Fix perspective-induced speed creep, add an always-on 1:1 pixel-locked 4-corner Speed Zone drag setter, add a live multi-dataset camera switcher, and replace cramped cards with a 2-tab Violations + Live Telemetry Log panel with CSV export.

---

## Locked Requirements

1. **REQ-7.5.1 [Live Multi-Dataset Camera Switcher]**
   - **Target:** Zone A provides a Camera Preset selector switching live between:
     - `highway_expressway` (`data/demo/highway_expressway.mp4`, 6-Lane Expressway `MVI_40191`)
     - `urban_arterial` (`data/demo/urban_arterial.mp4`, 8-Lane Urban Intersection `MVI_40712`)
     - `overhead_closeup` (`data/smoke_test/sample_traffic.mp4`, Close-Up Overhead)
   - **Acceptance:** `POST /api/camera` hot-swaps `UniversalCCTVStream` + loads preset `src_points`, `real_width_m`, `real_length_m`, and `speed_limit_kmh` without restarting uvicorn.

2. **REQ-7.5.2 [Steady Ground-Plane Speed Physics]**
   - **Target:** Deduplicate vision loop ticks by `frame_id`, use deterministic frame timestamps (`frame_id / fps`) on local MP4s, and compute velocity via least-squares linear regression over the rolling trajectory window (`min_samples >= 8`).
   - **Acceptance:** `test_homography.py` passes (`< 1e-4 m` projection error & jitter rejection), and vehicle speeds remain steady across the calibration zone rather than climbing near `P1–P2`.

3. **REQ-7.5.3 [Always-On 1:1 Pixel-Locked 4-Corner Zone Setter]**
   - **Target:** Lock `#calibrationSvg` inside a strict `16:9` wrapper matching `#cctvStream` pixels 1:1; display draggable `P1–P4` handles directly on the footage with instant auto-save on release, plus `Width (m)` / `Length (m)` inputs and `Reset Zone`.
   - **Acceptance:** Dragging any corner updates the SVG polygon and saves via `POST /api/calibration` with zero coordinate drift.

4. **REQ-7.5.4 [Clear 2-Tab Violations & Live Telemetry Log + CSV Export]**
   - **Target:** Zone C provides a **`Violations`** tab (readable cards with click-to-zoom snapshot) and a **`Live Log`** tab (tabular log of all tracked vehicles in-zone with `OK / WARN / VIOLATION` status), plus **`Export CSV`**.
   - **Acceptance:** WebSocket streams both `TELEMETRY_LOG` and `VIOLATION` events; Export CSV downloads a clean `.csv` file.
